# 平台说明

## 匿名获取与浏览器隔离

- 对 URL 输入，先尝试匿名公开元数据和字幕；调用 `yt-dlp` 时加 `--ignore-config`，不传 Cookie、浏览器 Cookie 导入或账号凭据，避免外部配置隐式启用登录态。
- 需要页面交互、播放或关键画面时，优先考虑 Codex 内置浏览器，但必须先根据当前工具说明或启动参数确认它与个人浏览器分离、未载入账号状态。不能仅凭“内置”“专用”或页面上没有头像判断隔离成立。
- 内置浏览器不适用时，可用 `agent-browser` 等工具启动全新的独立上下文或空配置目录。使用任务专属会话；不连接已有个人 Chrome/CDP，不启用自动连接，不加载个人 profile、扩展、认证状态文件或会话恢复；检查实际生效的配置和环境变量是否会启用这些行为。仅设置会话名称或打开新的普通标签页不构成登录态隔离。
- Agent-Reach/OpenCLI 等后端也必须确认匿名运行、不会从用户浏览器自动复制登录态，才能用于本任务。无法确认时跳过该后端，改用匿名公开入口，并记录限制；不要通过读取个人 Cookie 或会话存储来验证隔离。
- 视频页、短链接跳转、第三方解析页和下载回退使用同一匿名边界。浏览器路线不可用或采集失败时，不自动切回个人 Chrome，不自动要求用户登录；其他匿名渠道仍失败时，请用户提供本地视频或导出字幕。
- 普通登录提示可继续尝试匿名渠道；遇到验证码、明确风控拦截或限流则停止对该平台的请求，记录原因，不换账号、后端或浏览器连续尝试。不绕过登录、付费或访问限制，不点赞、评论、关注或投稿。
- 匿名渠道仍不足时，B站、抖音可走下述 PeanutDL 下载回退，再用本地视频提取音频、转写和补充必要画面。结果的“证据与处理说明”记录实际获取渠道、匿名会话方式及失败阶段；不记录凭据。

## YouTube

- 使用 `yt-dlp` 获取元数据和字幕。
- 优先使用人工上传字幕，再考虑自动生成字幕。
- 如果只有英文字幕，保留原意并将最终内容输出为中文，同时说明原始字幕为英文。

```powershell
yt-dlp --ignore-config --write-info-json --write-auto-subs --write-subs --sub-langs "zh.*,en.*" --skip-download -o ".video-summary-radar/outputs/%(title).200s/%(title).200s.%(ext)s" "<url>"
```

## Bilibili

- `yt-dlp` 通常可以获取元数据，字幕能力取决于视频。
- 页面内容和字幕不足以恢复主要内容时，使用 [PeanutDL B站下载](https://peanutdl.com/zh/bilibili)，按下述下载回退流程处理。
- 标题、简介、UP 主和章节可以辅助标注时间线，但主要观点必须来自字幕或转录。

## Douyin

- 分享链接可能经过短链接跳转，尽量先解析最终 URL。
- 仅通过匿名公开入口或已确认隔离且未登录的浏览器读取视频页章节、可见字幕、文案与必要画面；不使用已有登录态或会自动复制个人登录态的后端。
- 浏览器与公开字幕均不足以恢复主要内容时，使用 [PeanutDL 抖音下载](https://peanutdl.com/zh/douyin)，按下述下载回退流程处理。该入口用于抖音，不作为 TikTok 的默认下载入口。
- 短视频仍应按问题、方法、证据和结论组织，不应以冗长时间线充数。

## PeanutDL 下载回退（B站 / 抖音）

仅在页面、播放内容或字幕无法可靠读出主要内容时使用；已取得足够内容则无需额外下载。用户要求获取视频内容时，下载公开可访问的视频属于该获取流程，不必为进入下载页再次询问。

1. 在已确认隔离且未登录的浏览器中，按来源平台打开上面的对应页面，检查当前可见界面。没有符合隔离要求的可用浏览器时，记录该回退无法执行，不改用个人 Chrome。将用户提供的视频 URL（或已解析的最终 URL）填入链接输入框，点击“获取视频”（以当前页面为准）；不要把整段分享文案当成 URL，也不要根据标题换成其他视频。
2. 从解析结果中核对标题、封面、时长等可用信息，确认是目标视频；B站多分 P 时核对目标分 P。选择能满足转写和必要画面识别的下载结果，不默认下载全部清晰度或全部分 P。
3. 通过解析结果的下载按钮或视频另存为入口，配合当前浏览器工具的下载能力，将实际媒体保存到 `.video-summary-radar/outputs/<safe-video-title>/source/`；批量作业则保存到该作业的内容包目录下。下载链接临时有效，应及时保存媒体。确认得到可读取的媒体文件，而非解析页、广告页或仅一个下载链接。记录原视频 URL、PeanutDL 页面 URL、下载文件路径及实际失败信息（如有）。
4. 使用现有 `extract_audio.py`、`transcribe.py` 和 `normalize_transcript.py` 继续提取与整理内容；必要时查看本地关键画面。下载成功不等于转写完成，PeanutDL 只作为媒体获取渠道，不作为视频观点的证据来源。
5. 解析失败、无目标资源、页面不可用或工具不能保存媒体时，记录具体阶段和原因；无法继续时交付已确认内容，并请用户提供本地视频或导出字幕。遇到验证码、风控、限流或实际登录要求时停止该路线，不默认要求用户登录、操作个人浏览器或换浏览器重试。

## 本地视频

- 将用户提供的路径视为来源文件。
- 使用 `ffmpeg` 提取音频。
- 如果文件名包含有意义的标题，可作为默认标题。

## 转录

- 本地转录只使用 FunASR 中文后端。
- ASR 模型默认位于 `<workspace>/.video-summary-radar/runtime/models/SenseVoiceSmall`，缺失时报告准确路径。
- `<workspace>/.video-summary-radar/runtime/models/FSMN-VAD` 和 `PUNC` 为可选模型。
- FunASR 模型文件不会自动下载。
- Windows CPU 部署时，`torch` 与 `torchaudio` 使用匹配版本；安装器会使用 CPU 软件源。
- 最终内容包记录实际转录后端、模型来源和转录限制。

## 依赖设置

- Python 必须为 3.10 或更高版本。
- Python 依赖安装在工作区私有的 `.video-summary-radar/runtime/venv/`。
- 模型安装在工作区私有的 `.video-summary-radar/runtime/models/`。
- 使用 `where.exe ffmpeg`（Windows）或 `which ffmpeg`（macOS）检查 `ffmpeg`。
- 手动安装 `ffmpeg` 使用 `winget install Gyan.FFmpeg` 或 `brew install ffmpeg`。

## 隐私与访问

- 不绕过私有、付费、需要登录或受限制的内容。
- 区分公开视频页面的普通登录提示与内容本身的访问限制：前者可继续尝试匿名公开字幕和 PeanutDL；私有、付费或本身需要额外权限的内容，请用户提供有权使用的本地文件、导出的字幕或转录稿。只有用户另行明确要求使用账号并指定范围时，才讨论授权访问；本流程不自动发起登录，也不将账号授权扩大到其他视频或批量任务。
