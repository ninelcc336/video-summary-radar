# 视频转录后端两档配置设计

## 目标

为 `video-content-digest` 增加可选的两档转录后端，在控制磁盘占用的同时提升中文视频处理效果。默认使用中文优先方案，并保持现有 `faster-whisper` 流程可用。

## 范围

- 增加 `light`、`chinese` 两档配置。
- 统一所有转录后端的输出结构：`start`、`end`、`text`、`language`、`backend`。
- 依赖检查按后端区分，不自动下载模型。
- 在文档中说明模型占用、安装方式、选择建议和回退策略。
- 保持现有命令兼容；未指定后端时使用 `chinese`。

## 后端定义

| 后端 | 定位 | 实现策略 |
| --- | --- | --- |
| `light` | 低磁盘占用、快速处理 | 使用 `faster-whisper` tiny/base，沿用现有脚本 |
| `chinese` | 中文普通话默认方案 | 预留 FunASR 适配接口，支持 VAD、ASR 和可选标点模型 |

FunASR 的具体 checkpoint 通过参数或配置传入，不在代码中硬编码单一仓库，避免模型名称变化导致流程失效。

## 数据流

```text
音频文件
  -> 选择 backend
  -> 后端转录
  -> 统一段落结构
  -> normalize_transcript / 内容生成
```

统一结果示例：

```json
{
  "start": "00:00:03",
  "end": "00:00:08",
  "text": "这是中文转录结果。",
  "language": "zh",
  "backend": "chinese"
}
```

## 错误处理

- 未安装所选后端依赖时，输出明确的安装命令。
- FunASR 后端未配置模型时，不自动下载，提示用户补充模型路径或模型名。
- `chinese` 失败时允许显式启用回退到 `light`，不默认静默切换。
- 输出中记录实际使用的后端和转录限制。

## 验收标准

- 旧的 `faster-whisper` 命令仍能运行。
- 可通过参数选择两档后端。
- 未指定后端时默认值为 `chinese`。
- 依赖检查不会自动下载 FunASR 模型。
- 两档配置和安装说明与实际命令一致。
- 无模型或依赖时，错误信息能指向具体解决方式。
