# 贡献指南

当前仓库暂不收录第三方新增 skill；欢迎通过 Issue 或 PR 提交现有技能的缺陷修复、测试、文档和兼容性改进。

## 稳定技能的准入条件

进入 `skills/` 前必须满足：

1. 包含有效的 `SKILL.md` front matter（至少有 `name` 和 `description`）。
2. 脚本具备函数级说明，且不会隐式安装依赖、下载模型或执行破坏性操作。
3. 单元测试与本地脱敏 fixture 端到端测试通过。
4. 不包含虚拟环境、模型、缓存、密钥、Cookie、真实账号清单或真实任务输出。
5. Windows、macOS、Linux 的路径和命令均已验证或有明确降级说明。

## 版本与提交

仓库整体使用语义化版本。请在变更中更新 `CHANGELOG.md` 的 Unreleased 区域；提交信息使用中文。
